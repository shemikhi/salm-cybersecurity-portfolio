Building a Cybersecurity Home Lab on a Budget

2025-06-15 · 12 min read · Salm Bashemakh

Why Build a Home Lab?

You can't defend what you don't understand. A home lab lets you break things safely, build detections, and demonstrate skills to employers — all without risking production systems.

Hardware Requirements

Minimum viable setup:

  • CPU: 4 cores (8+ recommended)
  • RAM: 16GB (32GB+ recommended)
  • Storage: 200GB SSD
  • Hypervisor: VMware Workstation Pro (free for personal use) or VirtualBox

Step-by-Step Setup

1. Domain Controller

  • Install Windows Server 2019/2022
  • Promote to Domain Controller (corp.local)
  • Create test users and service accounts
  • Register SPNs for Kerberoasting practice

2. Client Workstations

  • Install Windows 10 Enterprise
  • Join to domain
  • Install Sysmon with SwiftOnSecurity config
  • Enable Windows Event Forwarding to Splunk

3. Splunk SIEM

  • Download Splunk Enterprise (free 500MB/day license)
  • Install Universal Forwarder on all Windows hosts
  • Configure inputs for Windows Security, Sysmon, and PowerShell logs

4. Kali Linux

  • Install Kali Linux 2024.x
  • Tools to install: Impacket, BloodHound, Rubeus, Mimikatz
  • Configure network adapter in NAT/Host-Only mode

First Attack Chain to Practice

  1. Reconnaissance with BloodHound
  2. Kerberoasting with Rubeus
  3. Crack the hash with Hashcat
  4. Lateral movement with PSExec
  5. Build detections in Splunk for each step

Cost Breakdown

Total: $0 (all software has free/trial versions)

  • VMware Workstation Pro: Free for personal use
  • Windows Server/10: 180-day evaluation
  • Splunk: Free 500MB/day license
  • Kali Linux: Always free
